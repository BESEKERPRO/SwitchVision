# SwitchVision

SwitchVision is an open-source Windows application designed to receive and display a Nintendo Switch video stream directly on PC using SysDVR.

## 🎮 How it works

Nintendo Switch
       ↓
     SysDVR
       ↓
      USB
       ↓
   SwitchVision
       ↓
    H.264 / FFmpeg
       ↓
   PC Display

## ✨ Features

- Direct SysDVR USB connection
- Native WinUSB communication
- H.264 video stream reception
- FFmpeg-based video decoding
- Local video rendering
- USB device detection
- USB diagnostics
- Video configuration
- FPS monitoring
- Fullscreen mode
- Simple graphical interface

## 🛠️ Technologies

- Python
- WinUSB
- SysDVR protocol
- H.264
- FFmpeg

## 🚧 Development Status

SwitchVision is currently under active development.

The main objective is to create an independent SysDVR client capable of receiving the Switch video stream directly inside SwitchVision instead of relying on the SysDVR-Client video window.

Some features may still be experimental or incomplete.

## 📋 Requirements

- Windows
- Nintendo Switch compatible with SysDVR
- SysDVR installed and configured
- USB connection
- FFmpeg
